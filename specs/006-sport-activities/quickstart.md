# Quickstart: validate activities

Gates: `dart format --set-exit-if-changed . && flutter analyze && flutter test -j 1`.

On the phone:
1. Train tab → **Log activity** → Running → Save. History shows it on top with a running icon; the gym workouts show a dumbbell icon.
2. Log Snowboarding for yesterday, 180 min, note "powder day". It shows under yesterday with "3 h · powder day".
3. Train tab: **This week** grew by 2, **Total workouts** did not. Progress: this week's bar includes them.
4. History → tap the Running entry → change to Cycling → Save; tap it again → Delete → confirm. It disappears.
